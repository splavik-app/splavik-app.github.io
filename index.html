Splavik

Карта рек и водных маршрутов для сплава.

  • Пороги, стоянки, места для старта и финиша на реках России.
  • Маршрут по реке с расстоянием, временем и ночёвками по дням.
  • Маршруты по шхерам в обход островов.
  • Карты можно скачать заранее и пользоваться без интернета.
  • Экспорт маршрута в GPX для навигаторов.
